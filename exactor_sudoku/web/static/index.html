Phase 1 • O(1) Fast-Path

1. Naked Singles Deterministic Deduction

For any empty cell $(r, c)$, let its candidate set $\mathcal{C}(r, c)$ be defined by eliminating all digits in its intersecting row, column, and $3 \times 3$ block:

$$\mathcal{C}(r, c) = \{1, 2, \dots, 9\} \setminus \Big(\text{Row}(r) \cup \text{Col}(c) \cup \text{Box}(b)\Big)$$ $$\text{If } |\mathcal{C}(r, c)| = 1 \implies \text{Value}(r, c) = \text{Unique}(\mathcal{C}(r, c))$$
⚡ Complexity: $O(1)$ bitwise lookup 🎯 Precision: 100% Deterministic
Phase 2 • Unit Coverage

2. Hidden Singles Across 27 Interlocking Units

Within any unit $U \in \{\text{Rows}, \text{Columns}, \text{Blocks}\}$, if digit $d$ can legally appear in exactly one cell, that digit is forced without backtracking:

$$\forall U \in \mathcal{U}, \quad \text{Count}\big(\{(r, c) \in U \mid d \in \mathcal{C}(r, c)\}\big) = 1 \implies \text{Value}(r, c) = d$$
⚡ 27 Parallel Units evaluated simultaneously 🛡️ Eliminates 85% of guessing
Phase 3 • Global Consistency

3. Minimum Remaining Values (MRV) Entropy Bifurcation

When all Singles are exhausted on Evil/Extreme puzzles, Exactor selects the cell with minimum entropy $|\mathcal{C}(r, c)| = 2$ and performs Boolean Unit Propagation:

$$(r^*, c^*) = \arg\min_{(r, c) \in \text{Empty}} |\mathcal{C}(r, c)|$$ $$\text{Constraint Clause: } \bigvee_{v \in \mathcal{C}(r^*, c^*)} X_{r^*, c^*, v} = \text{True}$$
⚡ Sub-millisecond SAT propagation 🚫 0 False Hallucinations
