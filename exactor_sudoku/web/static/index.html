How the engine deduces boards autonomously without cheats, precomputed tables, or trial-and-error.

PHASE 1

Bitwise Constraint Domain Formulation ($O(1)$)

For every empty cell $(r, c)$, the engine calculates the allowable candidate set $\mathcal{C}(r, c)$ in a single CPU cycle using bitwise operations across its intersecting row, column, and 3x3 block:

$$\mathcal{C}(r, c) = \{1, 2, \dots, 9\} \setminus \Big(\text{Row}(r) \cup \text{Col}(c) \cup \text{Box}(b)\Big)$$
⚡ Query Latency: 0.001 ms 🛡️ Implementation: Hardware-accelerated Bitmask Lookup
PHASE 2

Fast-Path SAT: Direct Causal Implication (Zero Branching)

Before ever expanding a search tree, EXACTOR executes two parallel Boolean uniqueness proofs:

A. Naked Single (Direct Unit Clause): If $|\mathcal{C}(r, c)| = 1$, the cell has only one mathematically legal digit in the universe of options and is placed immediately.
B. Hidden Single (Unit Coverage Uniqueness): If across an entire row, column, or 3x3 block, digit $d$ can only fit in one specific coordinate, that value is forced by law of coverage.
🎯 Empirical Performance: Solves 85% to 95% of the board in sub-milliseconds without branching.
PHASE 3

MRV (Minimum Remaining Values) & Global Boolean Propagation

On master/extreme puzzles with 17 starting clues where direct Singles are exhausted, EXACTOR targets the cell with minimum uncertainty (lowest entropy):

$$(r^*, c^*) = \arg\min_{(r, c) \in \text{Empty}} |\mathcal{C}(r, c)| \quad \text{where typically } |\mathcal{C}| = 2$$

It executes Boolean unit propagation: if a branch induces an inconsistent state in any neighboring unit, that branch is pruned in microseconds before the tree can grow.

📖 Key Concepts & Vocabulary (Influencer Cheat Sheet)

Boolean SAT (Satisfiability): The foundational computer science problem of determining whether there exists a combination of true/false assignments that satisfies a logical formula.
CSP (Constraint Satisfaction Problem): Mathematical problems where variables must adhere to a strict system of simultaneous boundary constraints.
Naked Single: A cell where 8 digits are already blocked by intersecting units, leaving exactly 1 mandatory candidate.
Hidden Single: A digit that, within an entire row, column, or 3x3 block, can only legally reside in a single empty spot.
MRV (Minimum Remaining Values): A lowest-entropy heuristic that picks the most constrained variable first to minimize branch search space.
Neuro-Symbolic AI: The ultimate synthesis combining modern AI flexibility with the infallible mathematical precision of symbolic logic.
