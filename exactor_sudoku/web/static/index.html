1. Naked Singles Deduction ($\mathcal{O}(1)$ Fast-Path)

For any cell $(r, c)$, let $\mathcal{C}(r, c) = \{1..9\} \setminus (\text{Row}(r) \cup \text{Col}(c) \cup \text{Box}(b))$. If $|\mathcal{C}(r, c)| = 1 \implies$ direct placement.

2. Hidden Singles Across 27 Interlocking Units

If digit $d$ appears as a candidate in exactly one cell within a unit $U \in \{\text{Rows}, \text{Cols}, \text{Boxes}\}$, then that cell must take $d$.

3. Minimum Remaining Values (MRV) Entropy Bifurcation
